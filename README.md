# AutoAI Android MVP

Первый прототип автономного агента для Android.

## Что уже есть
- Android + Kotlin + Jetpack Compose
- агентный цикл до 8 шагов
- LLM принимает решение, какой инструмент вызвать
- calculator
- память в процессе работы
- current_time
- журнал действий в UI
- WorkManager подключён для следующего этапа

## Запуск
1. Открой проект в Android Studio.
2. Дождись синхронизации Gradle.
3. В `LlmClient.kt` укажи OpenAI-compatible endpoint, API key и model.
4. Запусти приложение на телефоне/эмуляторе.

## Важно
Не хранить настоящий API-ключ в APK для публичного приложения. Для production вынести секрет на сервер/прокси.
